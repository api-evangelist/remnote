# RemNote

> RemNote is an AI-powered note-taking, spaced-repetition, and PDF-annotation study platform (founded at MIT, backed by General Catalyst). For developers it exposes a first-party front-end Plugin SDK — a React-first, sandboxed extension platform with a Rem API, hooks, widgets, and virtual embeds — rather than a hosted backend REST API. ## Notes

- No hosted backend REST API: RemNote states it does not host a backend API and directs developers to the front-end API instead. There is therefore no OpenAPI, OAuth scope surface, webhook/AsyncAPI event surface, or REST error catalog to capture.
